# BlueprintOrganizer

Adds **search, tags and virtual folders** to the load blueprints menu for making organization easier.

<img width="610" height="744" alt="image" src="https://github.com/user-attachments/assets/3c05d4a3-ed39-4272-b02d-53d9857a0ce3" />

##  Notes

* When installing the mod, **nothing** appears in the **"Tags"** or **"Folders"** section; you will have to select a **blueprint** and assign it a **Tag** or a **Folder** *(you can assign both).*
* If the **"blueprint_meta.json"** file is *deleted* from the **mod folder**, **all tags and folders** will be **deleted for all rockets**.


---


##  Installation

1. Ensure you have **Spaceflight Simulator +1.6.0.0**.
2. Download the **latest release** file.
3. Place the file `SFSBlueprintOrganizer.dll` on "C:\Program Files (x86)\Steam\steamapps\common\Spaceflight Simulator\Spaceflight Simulator Game\Mods"
